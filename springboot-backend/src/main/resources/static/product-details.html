Women's Size Guide

Standard international sizing measurements in inches (and cm).

Size Bust Waist Hips
S (US 4-6) 33-35" (84-89 cm) 26-27" (66-69 cm) 36-37" (91-94 cm)
M (US 8-10) 36-37" (91-94 cm) 28-30" (71-76 cm) 38-40" (97-102 cm)
L (US 12-14) 38-40" (97-102 cm) 31-33" (79-84 cm) 41-43" (104-109 cm)
XL (US 16-18) 41-43" (104-109 cm) 34-36" (86-91 cm) 44-46" (112-117 cm)

💡 How to measure: Keep the measuring tape comfortable and parallel to the floor.

👗 If you fall between two sizes, we recommend selecting the larger size for a relaxed drape.
